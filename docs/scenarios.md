# EPCSE — مصفوفة السيناريوهات والتحقق

**خطة اختبار فقط؛ لا اختبارات منفذة ولا نتائج أو baselines مقاسة.** المصدر [§8 و§11–12 و§18](reference/original-spec-ar.md)، والمتطلبات [FR-01–12](product-spec.md) مع إضافات الرؤية المعتمدة، والتنفيذ المستقبلي [T00–T26](tasks.md). العقود غير المعتمدة في [decisions.md](decisions.md)، والتكامل في [delegation.md](delegation.md).

## 1. بروتوكول مشترك

كل SC يملك ملفي سيناريو/اختبار مستهدفين `packages/scenarios/src/SC-NN.ts` و`tests/scenarios/SC-NN.test.ts`. يثبت Config ونسخة القواعد والمحرك وSeed والأوامر وترتيبها ومدة الرصد قبل الاختبار. الرقم NN يطابق رقم المصدر، ولا تستبدل هذه IDs بأرقام نجاح قالب Spec Kit.

تقارن الصدمة بخط أساس من الحالة نفسها؛ تُقاس الآثار **اتجاهيًا وتحت شروط fixture**، لا بتنبؤات لدولة حقيقية أو أرقام مخرجات جاهزة. الثوابت المحاسبية والوقتية دقيقة؛ نطاقات المعايرة تُعتمد وتُنسخ، لا تُعدّل للحصول على نجاح. يثبت fixture مصالح/ميزانية/قدرة الأطراف بحيث يمكن اختبار قرار معين، مع ضابط رفض مستقل؛ لا يفرض السيناريو القرار داخل المحرك. بذور متعددة مخططة للحساسية بعد اعتماد مجموعة البذور، وتُسجل البذرة الفاشلة لإعادة الإنتاج.

كل الصفوف أدناه **مخططة وغير مختبرة**. مستهدفها M1 (بعض أدلتها تبدأ S0/VS). لا سيناريو مؤجل معتمد حاليًا؛ SC-11 فقط يحتاج ضبط حدود التفصيل مقابل M2+ عبر Q08.

## 5. طبقات التحقق والأوامر المقترحة

**الأوامر التالية ليست متاحة الآن ولم تُشغّل.** ينشئ T02 scripts الجذر `typecheck/lint/test/build/cli/bench/test:e2e` وVitest include لمسار `tests/`، ويفوض `cli` إلى التطبيق و`test:e2e` إلى Playwright. لا تثبيت ولا خدمات في جلسة التخطيط. المسارات أعلاه هي العقد المطلوب لا افتراض وجود ملفات.

```sh
# بعد إذن التنفيذ وتجهيز المشروع، من الجذر
pnpm typecheck
pnpm lint
pnpm exec vitest run tests/unit tests/contract tests/property
pnpm exec vitest run tests/integration/s0.test.ts
pnpm cli run --scenario initial-two-cities --seed 42 --ticks 100
pnpm exec vitest run tests/integration/vs.test.ts
pnpm cli run --scenario vertical-slice --seed 42 --ticks 1000
pnpm exec vitest run tests/integration/determinism.test.ts tests/integration/restore.test.ts
pnpm exec vitest run tests/scenarios/SC-02.test.ts tests/scenarios/SC-15.test.ts
pnpm exec vitest run tests/scenarios tests/regression
pnpm test
pnpm build
# لاحقًا، بعد إذن بيئة محلية مؤقتة وقاعدة/API حقيقيين
pnpm exec vitest run tests/integration/persistence.test.ts tests/api
pnpm test:e2e
pnpm bench --scenario three-nations-trade-and-politics --seed 42 --ticks 1000
```

- **وحدة/عقود/خصائص:** مع كل تغيير؛ تشمل imports وcodec والمراحل والتحويلات والقرارات المنفردة.
- **تكامل:** إنتاج → نقل → سوق → استهلاك ثم سياسة/دبلوماسية؛ على CI وعند كل دمج، لا نجاح mocks فقط.
- **تكرار/انحدار:** على CI وكل تغيير Tick/RNG/مال/قواعد؛ baselines بنسخها وأسباب تحديثها، لا إعادة توليد آلية لإخفاء اختلاف.
- **حفظ:** round-trip في الذاكرة مبكرًا؛ PostgreSQL فعلي وفشل كتابة/نسخة وتواصل عند T17؛ سجل الأحداث ليس دليل event replay كامل.
- **API/E2E:** ترتيب متزامن وصلاحيات/idempotency ثم رحلة متصفح فعلي عبر API حقيقي. يميز التقرير بوضوح fake أو API-only أو فحص عرض غير بصري.
- **أداء:** بعد VS وعلى M1؛ قياس 3/12/100 مدينة (الأخيرة استكشاف لا التزام M1)، الجهاز وNode والنسخ، warmup وتكرارات وذاكرة/مراحل/أعداد. مقارنة ذاكرة نقاط مستقرة بعد إحماء وGC موثق إن استُخدم، لا استنتاج تسرب من عينة واحدة. سقف سرعة/ذاكرة بعد Q10 فقط، لا أرقام مدعاة الآن.

## 6. سجل الدليل والتأجيل

عند التنفيذ يسجل لكل SC: النسخ، Seed، hash Config/الأوامر، التدخل، مدة الرصد، الأمر الفعلي، المقاييس/baseline، النتيجة والدليل واسم المراجع. نجاح الاختبار المركز لا يساوي نجاح DoD.

DoD الأصلي يطلب SC-01–17 **مع توثيق أي سيناريو مؤجل خارج M1**؛ وتُضاف SC-18–20 كقبول مخطط لتوجيهات المستخدم الجديدة، دون تغيير نص خط الأساس الأصلي. أي استثناء يسجل: ID، السبب، الجزء المؤجل، أثره على FR/DoD، البديل المختبر، المالك، موافقة ممدوح وتاريخها، وشروط العودة. لا يستبدل نجاحًا ولا يؤجل SC-11 تلقائيًا. الحالة الآن لجميع الصفوف: مخطط، لا دليل، لا تأجيل معتمد. إغلاق DoD-01–12 يتم عند T22 حسب [مواصفة المنتج §6](product-spec.md#6-تعريف-الإنجاز-الأصلي-لـm1-18--لم-يتحقق-أي-بند-بعد).
