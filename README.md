# EPCSE — Economic, Political & Civilization Simulation Engine

A planned deterministic simulation of interconnected economies, cities, populations, governments and diplomacy. The engine is intended to run independently of a user interface, web server or database.

**Status:** planning only; no simulation engine, runnable application, measured performance, or passing software tests yet. The project requirements and design are subject to review and decisions by the project owner.

The planning documentation is proposed separately for review. The intended stack is TypeScript and Node.js, with a standalone simulation core and CLI; API, persistence and visualization are to be integrated later as part of the same project.
